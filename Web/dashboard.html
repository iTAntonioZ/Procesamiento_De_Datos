¿Cómo funciona SHA-256?

SHA-256 genera una huella digital de 256 bits a partir del contenido de un archivo.

Al comparar el resultado con un hash de referencia confiable, podemos comprobar si el contenido coincide.

El cálculo se realiza localmente en el navegador. El archivo no se envía al servidor.
